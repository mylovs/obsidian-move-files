# 需求文档

## 1. 需求背景

### 1.1 项目概述

本项目旨在开发一个用于Obsidian笔记应用的文件移动工具插件，帮助用户更高效地管理和组织笔记文件及其引用的附件。

### 1.2 业务目标

- 提高用户在Obsidian中管理文件的效率
- 提供便捷的文件移动操作体验
- 支持批量文件处理和按扩展名分类选择
- 确保文件移动过程的安全性和可靠性
- 支持撤销操作，防止误操作

### 1.3 目标用户

- Obsidian笔记应用的普通用户
- 需要频繁整理笔记文件的重度用户
- 团队协作场景下的文件管理员

***

## 2. 功能需求

### 2.1 核心功能

| 功能编号 | 功能名称    | 功能描述                                      | 优先级 |
| :--- | :------ | :---------------------------------------- | :-- |
| F001 | 引用文件分析  | 分析当前打开的markdown文件中引用的所有外部文件（md文件、图片、附件等） | 高   |
| F002 | 扩展名分类选择 | 根据引用文件的扩展名进行分类展示，支持按类别选择移动                | 高   |
| F003 | 批量文件移动  | 支持选择多个文件并批量移动到指定目录                        | 高   |
| F004 | 移动源文件    | 支持将当前打开的markdown文件本身也移动到目标目录                | 高   |
| F005 | 自动创建目标文件夹 | 移动文件时自动创建目标文件夹，默认名称为当前打开的md文件名（不含扩展名） | 高   |
| F006 | 冲突处理    | 当目标路径存在同名文件时自动跳过该文件的移动                      | 中   |
| F007 | 移动预览    | 移动前显示将被移动的文件列表和目标路径                       | 中   |
| F008 | 移动历史记录  | 记录所有文件移动操作，支持按时间戳分组查看                      | 中   |
| F009 | 批量撤销移动  | 支持按时间戳撤销同一批次移动的所有文件                        | 中   |

### 2.2 辅助功能

| 功能编号 | 功能名称  | 功能描述            | 优先级 |
| :--- | :---- | :-------------- | :-- |
| F010 | 快捷访问  | 通过命令面板和侧边栏图标快速触发 | 中   |
| F011 | 移动确认  | 移动操作完成后显示确认提示并自动关闭 | 低   |
| F012 | 历史清空  | 支持清空所有移动历史记录     | 低   |

***

## 3. 非功能需求

### 3.1 性能需求

- 单文件移动响应时间 ≤ 500ms
- 批量移动100个文件时间 ≤ 10s
- 支持移动大文件（最大100MB）

### 3.2 安全性需求

- 移动过程中发生异常时不影响已移动文件
- 提供移动历史记录支持撤销
- 防止误删除文件

### 3.3 兼容性需求

- 支持Windows 10及以上版本
- 支持macOS 10.15及以上版本
- 支持Linux主流发行版
- 兼容Obsidian v1.0.0及以上版本

### 3.4 用户体验需求

- 操作流程简洁直观
- 界面响应迅速
- 提供清晰的错误提示信息
- 支持响应式布局

***

## 4. 验收标准

### 4.1 功能验收标准

| 功能编号 | 验收条件                      |
| :--- | :------------------------ |
| F001 | 打开md文件后，能正确识别并列出所有引用的外部文件 |
| F002 | 引用文件按扩展名分类展示，支持按类别勾选选择移动  |
| F003 | 用户选择多个文件后，可批量移动到指定目录      |
| F004 | 勾选"Move this file"后，当前md文件也会被移动   |
| F005 | 移动文件时自动创建目标文件夹，默认名称为当前md文件名（不含扩展名） |
| F006 | 目标路径存在同名文件时，自动跳过该文件的移动    |
| F007 | 移动操作执行前显示即将移动的文件列表和目标路径   |
| F008 | 所有移动操作都被记录，按时间戳分组展示       |
| F009 | 支持按时间戳批量撤销同一批次的所有移动操作     |

### 4.2 性能验收标准

- 单文件移动响应时间 ≤ 500ms
- 批量移动100个文件时间 ≤ 10s

### 4.3 安全性验收标准

- 移动中断时已移动的文件保持在目标位置
- 撤销功能可恢复文件到原始位置
